## 安装

```bash
dsh plugin --profile desktop add ./dsh-collab-0.7.0.tgz
# 或源码包解压后：
dsh plugin --profile desktop add .
```

profile 里按 `id: dsh-collab` 覆盖配置：

```yaml
- id: dsh-collab
  name: dsh-collab
  config:
    bind: 0.0.0.0        # 局域网/远程协作必须显式打开；默认 127.0.0.1
    port: 8848
    allowPeers: 8
    ttlMinutes: 30
    adminToken: ''       # 空 = 控制台仅本机
```

重启一次 DSH，然后任意会话里 `/collab` 拿链接；agent 可用 `collab_share` 把链接写进回答。

## 这一版有什么

- **一条链接**：`http://<host>:8848/c/<room>#k=<secret>`，secret 只在 URL fragment，永不上线。
- **结构化视图**：历史回放 + 实时补丁（512 条环形缓冲）、逐 token 流式（80ms 合并 + 光标）、轻量 Markdown。
- **只读文件柜**：浏览 / 搜索 / 截断 / 脱敏；默认走 `ctx.fs`，失败回退 `node:fs`；每房间 JSONL 审计。
- **在场状态机**：`typing / reading / browsing / searching / idle`，聚合广播 + 6s/60s 衰减 + 200ms 节流。
- **留言与批注**：房间级消息 + 节点锚定；2000 字/房间 200 条/0.2 条每秒；可关闭。
- **主机控制台**：`/collab/admin` 房间、协作者、活动、留言、审计；刷新链接、关房、下载导出。
- **对话内面板**：设置 → 协作（手写 client bundle，无打包器）。
- **双语**：分享页与控制台 zh/en。
- **中心机**：`role: hub` 或独立 `dsh-collab-hub`，直连优先、失败中继。
- **Agent 工具**：`collab_share` / `collab_status` / `collab_inbox` / `collab_reply` / `collab_export`。

## 兼容性

- Node ≥ 22（全局 `WebSocket`、WebCrypto）。
- DSH ≥ 0.2.0-rc.2。
- 无运行时依赖，只用 Node 内置模块 + 宿主提供的 `@deepseek-ai/schemastery`。

## 安全模型

邀请 secret 256-bit（只在 fragment）→ HKDF 派生 AES-256-GCM，帧级加密；挑战应答双向证明；拒绝清单 + 脱敏 + 审计；无写入、无 shell、无代理；控制台默认 loopback，远程要 `adminToken`，写操作还要自定义头（CSRF）。

## 已知限制

- 宿主未发 `assistant-stream` 时视图退化为按步实时。
- 目录单层 400 项；二进制只报元数据；hub 中继带宽由中心机承担。
- 留言只在房间内存（关房即失效），导出文件会留下。
- 推送式"留言进 agent"不可行（服务面缺 turn 外注入），已用 `collab_inbox` 拉取式替代。
- 敏感路径的"主机确认"式放行未接（`ctx.approval` 要求请求方处于打开的 turn 内）。
